# Bundled font licenses

All fonts here are SIL Open Font License 1.1 — free to embed and redistribute.

- **Anton-Regular.ttf** — © The Anton Project Authors — [OFL](https://scripts.sil.org/OFL)
- **NotoSerif-Bold.ttf** — © The Noto Project Authors — [OFL](https://scripts.sil.org/OFL)
- **Inter-Bold.ttf** — © The Inter Project Authors (https://github.com/rsms/inter) — OFL
  ([full text](https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt)).
  Static Bold instance extracted from Google Fonts' variable `Inter[opsz,wght].ttf`
  with `fonttools.varLib.instancer` — same pattern as the other bundled weights,
  chosen over shipping the variable font directly for predictable libass/ASS burns.
- **Montserrat-Bold.ttf** — © The Montserrat Project Authors — OFL
  ([full text](Montserrat-OFL.txt)). Static Bold instance, same reasoning as Inter.
